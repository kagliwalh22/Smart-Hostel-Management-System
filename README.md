# Smart Hostel Management System (SHMS)

## Problem Statement
Traditional hostel management relies on manual spreadsheets, paper registers and decentralized records. This causes delays, data mismatch and no workflow validation. SHMS is a unified, secure, web-based system to automate student registration, room allocation, complaints, fees, attendance, visitor logs and out-passes for Students, Wardens and Admins.

## Tech Stack
- Frontend: React
- Backend: Node.js / Express
- Database: MySQL / PostgreSQL
